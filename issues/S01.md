# Tulis aturan kerja agar hasil endpoint konsisten
labels: enhancement, agent-ready, scenario:S01

## Konteks
Rani harus beberapa kali memperbaiki PR karena konvensinya belum tertulis. Bima ingin membandingkan hasil prompt yang sama dengan dan tanpa aturan.

## Acceptance criteria
- [ ] Bandingkan `GET /claims/:id/history` di dua worktree.
- [ ] Versi ber-instructions mengikuti pemisahan route/service, format `{code,message}`, dan logging tanpa PII.
- [ ] Endpoint menghormati akses klaim per tim dan punya test.

## Definition of done
Tunjukkan dua diff dan catat perbedaan yang benar-benar terlihat.
