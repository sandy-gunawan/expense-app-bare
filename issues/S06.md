# Ganti label Submit dan tambahkan petunjuk pengajuan
labels: enhancement, agent-ready, scenario:S06

## Konteks
Lina ingin karyawan tahu tombol mana yang mengirim klaim ke manager. Untuk akun personal, gunakan issue ini sebagai pengganti ticket Jira/Teams.

## Acceptance criteria
- [ ] Tombol memakai label “Ajukan Klaim”.
- [ ] Petunjuk tersedia dengan keyboard, bukan hanya saat hover.
- [ ] Request dan perilaku form tidak berubah.

## Definition of done
Tautkan PR ke ticket atau issue dan tangkap form sebelum/sesudah.

## Skenario workshop
S06 — Delegasi dari entry point bisnis.
