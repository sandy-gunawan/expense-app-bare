# Tambah pilihan kategori pada pengajuan klaim
labels: enhancement, agent-ready, scenario:S02

## Konteks
Bima ingin pengguna memilih kategori, bukan selalu menerima `Other`. Perubahan harus konsisten dari form sampai SQLite.

## Acceptance criteria
- [ ] Izinkan `Travel`, `Meals`, `Equipment`, dan `Other`; tolak nilai lain.
- [ ] Pertahankan klaim lama, gunakan kolom kategori yang sudah ada, dan jelaskan apakah migration benar-benar diperlukan.
- [ ] Isi dropdown, tampilkan kategori, dan uji alur dari form sampai API.

## Definition of done
Test API dan Playwright lulus; kontrak API diperbarui.
